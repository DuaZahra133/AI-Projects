# 📊 Superstore Sales Analysis & Machine Learning Project

---

## 🚀 Project Overview

This is an end-to-end **Data Science + Machine Learning project** built on a real-world retail dataset.

The goal is to transform raw sales data into:
- 📊 Actionable business insights  
- 🤖 Predictive machine learning models  
- 💼 Data-driven decision support  

---

## 🎯 Business Problem

Retail companies struggle with:

- Understanding what drives sales  
- Identifying profitable categories  
- Predicting future sales performance  
- Optimizing business strategy using data  

This project solves these problems using data analysis and machine learning.

---

## ⚙️ Project Workflow

✔ Data Cleaning & Preprocessing  
✔ Exploratory Data Analysis (EDA)  
✔ Feature Engineering  
✔ Machine Learning Model Building  
✔ Model Evaluation  
✔ Business Insight Extraction  

---

## 📊 Key Business Insights

- 📌 Technology category generates the highest revenue  
- 📌 Profitability varies significantly across categories  
- 📌 Sales show seasonal patterns over time  
- 📌 Regional performance is highly uneven  
- 📌 Sales ≠ Profit (important business insight)

---

## 🤖 Machine Learning Models

Two regression models were used:

### ✔ Linear Regression (Baseline Model)
- Simple and interpretable  
- Used for baseline comparison  

### ✔ Random Forest Regressor (Advanced Model)
- Captures non-linear relationships  
- Better predictive performance  

---

## 📈 Model Evaluation

Performance was measured using:

- R² Score  
- Mean Squared Error (MSE)  
- Actual vs Predicted Analysis  

👉 Random Forest performed better in capturing complex patterns in the data.
