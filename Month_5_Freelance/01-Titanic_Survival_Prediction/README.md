# 🚢 Titanic Survival Prediction - Machine Learning Project

---

## 🚀 Project Overview

This project is an end-to-end **Machine Learning classification task** using the famous Titanic dataset.

The goal is to predict whether a passenger survived or not based on features such as age, gender, ticket class, and more.

---

## 🎯 Objective

- Analyze passenger data from the Titanic disaster  
- Identify factors affecting survival  
- Build a machine learning model to predict survival  
- Understand classification workflow in ML  

---

## ⚙️ Project Workflow

✔ Data Cleaning & Preprocessing  
✔ Exploratory Data Analysis (EDA)  
✔ Feature Engineering  
✔ Model Building  
✔ Model Evaluation  
✔ Prediction Generation  

---

## 📊 Key Insights from Data

- 🚹 Gender played a major role in survival (female survival rate higher)  
- 🎟️ Passenger class impacted survival chances (1st class had higher survival)  
- 👶 Age distribution affected survival probability  
- ❌ Missing values required careful handling  

---

## 🤖 Machine Learning Models Used

### ✔ Logistic Regression 
- Simple and interpretable  
- Good baseline for classification  


---

## 📈 Model Evaluation

Model performance was evaluated using:

- Accuracy Score  
- Confusion Matrix  
- Precision & Recall  

👉 The model successfully learned survival patterns from historical data.
