# Month 3 – Deep Learning

This folder contains **7 AI & Deep Learning projects** completed during **Month 3** of my portfolio.  
The focus of this month was on **Neural Networks, Convolutional Neural Networks (CNNs), Sentiment Analysis, and AI App Development with Streamlit**.

---

## 🗂️ Projects Overview

### **Week 1 – Neural Networks (NN)**
1. **hello_worldnn.ipynb** – Introductory neural network “Hello World” project.  
2. **mnist_basic.ipynb** – MNIST digit recognition using basic NN.  
3. **activation_loss.ipynb** – Explored activation functions and loss functions.  
4. **training_eval.ipynb** – Training and evaluation of NN models.  
5. **final_model.ipynb** – Final MNIST model with evaluation.

### **Week 2 – Convolutional Neural Networks (CNN)**
6. **CNN_Image_Classification.ipynb** – CNN project for image classification (Fashion MNIST ).

### **Week 3 – Sentiment Analysis (NLP)**
7. **Sentiment_Analysis_IMDB.ipynb** – Text preprocessing, feature extraction (Bag-of-Words & TF-IDF), and sentiment classification.

### **Week 4 – Streamlit AI App**
- **Grade Predictor App** – Streamlit app folder contains:  
  - `app.py` – Main Streamlit application  
  - `requirements.txt` – Required packages  
  - `grade_model.pkl` – Trained model  
  - `screenshots/` – App visuals  

> Open the `app.py` in **Streamlit** to run the interactive AI app locally.
